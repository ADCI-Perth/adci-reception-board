# Auto-switching Reception Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One reception board on GitHub Pages that reads `data/Calendar.xlsx` and `data/Timetable.xlsx` and shows the right mode (teaching, summer, tuition-free, study, exam, assessment, semester break, Christmas) for today.

**Architecture:** Static site, no build step. Pure logic (date parsing, mode resolution, banners, timetable filtering, data checks) lives in ES modules under `assets/js/core/` and is unit-tested with `node --test`. Browser-only code (widgets ported from the existing HTML boards, layout, data loading) lives in `assets/js/board/` and is verified in a browser with `?date=` previews. Excel files are read in the browser with SheetJS; templates are generated by a Python/openpyxl script.

**Tech Stack:** HTML/CSS/vanilla JS (ES modules), SheetJS `xlsx@0.18.5` (cdnjs in browser, npm in tests), d3 3.5.17 / topojson 1.6.19 / datamaps 0.5.1 (unchanged), Node 25 `node --test`, Python 3.12 + openpyxl 3.1.5, GitHub Actions + Pages.

**Spec:** `docs/2026-11-20-auto-switching-reception-board-design.md`

## Global Constraints

- Repo: public `ADCI-Perth/adci-reception-board`; site URL `https://adci-perth.github.io/adci-reception-board/`. All asset paths relative (site is served from a sub-path).
- Dates in spreadsheets are **dd/mm/yyyy** (Australian). Never interpret as mm/dd. Internally every date is an ISO string `YYYY-MM-DD`; never construct `Date` from an ISO string without splitting (avoids UTC shift). Timezone = device local (Perth).
- Calendar rows copy the PDF: **one row per week, Start = Monday, End = Friday** as printed.
- Valid Types (case-insensitive, trimmed): `Orientation, Teaching, Tuition Free, Study, Exam, Assessment, Semester Break, Summer, Christmas, Event`.
- Mode priority (highest first): `christmas > exam > study > assessment > tuition > summer > orientation > teaching > break`. `Event` never sets the mode.
- External scripts only from cdnjs with exact versions; `xlsx` = `https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`.
- No visual redesign: CSS, markup and widget JS are ported from the base files, not rewritten. Base files: `Standard_reception_hub - v4.html` (teaching family), `Standard_reception_hub_tuition_free_week.html` (tuition), `Exam_Week_Hub.html` (exam), `Semester_Break_Hubv2.html` (study + break, and source of all widget JS), `Christmas_Version.html` (christmas).
- Weather key, city, durations, photo and video lists: copy from `Standard_reception_hub - v4.html` lines 369-387.
- The board must never go blank: any data failure falls back to cached data, then to `break` mode with generic text.

## Review Focus

1. **Dates typed as text or with stray spaces** (`"9/11/2026"`, `" 09/11/2026 "`, Excel serials, real date cells) must all parse as 9 Nov 2026; `"2026-11-09"` also accepted. → Task 1 test `toISODate accepts every format`.
2. **Days no row covers** (weekends, unlabelled gap weeks, a date after the last row) → weekend inherits the preceding Friday's period; otherwise `break` mode; countdown hidden when there is no next period. → Task 2 tests `weekend inherits Friday`, `gap week is break with countdown`, `past last row is break without countdown`.
3. **Overlapping rows** (Event on a teaching day, Summer row overlapping Christmas by mistake) → priority decides, events only add banner text. → Task 2 test `priority and events`.
4. **Spreadsheet unreachable, corrupt, or wrong sheet name** → cached copy used; with no cache the board shows `break` mode with "WELCOME TO ADCI" and keeps clock/weather/news. → Task 2 test `empty calendar resolves to break`; Task 6 manual step with renamed file.
5. **Excel-user mess**: blank rows, header case/spacing differences (`"start "`, `"START"`), extra columns, a class row with blank From/To or "9:00 am" times. → Task 4 tests `header normalisation`, `blank rows skipped`, `time formats`, `From/To default to whole term`.

### Task 2: Calendar parsing and day resolution

**Files:**
- Create: `assets/js/core/calendar.js`
- Test: `tests/calendar.test.js`

**Interfaces:**
- Consumes: Task 1 date helpers.
- Produces:
  - `normaliseRow(row: object) -> object` — keys lower-cased, trimmed, inner spaces collapsed (`"Banner text "` → `"banner text"`); string values trimmed. (Also used by Task 4.)
  - `parseCalendarRows(rows: object[]) -> Calendar` where `Calendar = { periods: Period[], events: Period[], errors: {row:number, message:string}[] }`, `Period = { type, name, start, end, term, banner, row }`. `type` is the mode key: `orientation|teaching|tuition|study|exam|assessment|break|summer|christmas|event`. `row` = spreadsheet row number (`row.__row`, header is row 1). Rows with every cell blank are skipped silently. Errors: unknown/missing Type, bad Start/End, End before Start.
  - `resolveDay(cal: Calendar, iso: string) -> DayState`:
    ```
    DayState = { mode, period: Period|null, block: {start,end}|null,
                 next: Period|null, countdown: {label, target}|null, events: Period[] }
    ```

**Rules (spec 5.4, decided here):**
- Covering = non-event periods with `start <= iso <= end`. Pick by Global Constraints priority. If none and `iso` is Sat/Sun, re-resolve as of the preceding Friday (mode/period/block from Friday; countdown still from real `iso`). If still none → `break`.
- `block` = the chosen period merged with neighbours of the same type where next.start ≤ prev.end + 3 days (Fri→Mon). For `break`, block = (previous non-event period end + 1, next period start − 1).
- `next` = earliest non-event period with `start > (block.end)` (for break: `start > iso`).
- Countdown (target ISO, label):
  - exam → `block.end + 1`, `"Exams Complete In"`
  - tuition → `next.start`, `"Classes Resume In"`
  - christmas → `next.start` if it exists else first weekday after `block.end`, `"Campus Reopens In"`
  - study, assessment, break → `next.start`, label by `next.type`: orientation `"Orientation Starts In"`, teaching/summer `"Classes Resume In"`, exam `"Exams Start In"`, study `"Study Week Starts In"`, tuition `"Tuition-Free Week Starts In"`, assessment `"Assessment Week Starts In"`, christmas `"Holiday Break Starts In"`.
  - teaching, summer, orientation → `null`. No `next` → `null`. `daysBetween(iso, target) <= 0` → `null`.
- `events` = Event rows covering `iso`.
